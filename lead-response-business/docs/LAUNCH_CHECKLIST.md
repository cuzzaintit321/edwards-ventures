# Deployment and client-readiness checklist

- [ ] Run automated tests and manual smoke test.
- [ ] Set strong `.env` credentials and keep them out of GitHub.
- [ ] Verify database volume is writable and persistent.
- [ ] Keep admin dashboard available only via protected access.
- [ ] Add production HTTPS and access restrictions before public availability.
- [ ] Add anti-spam rate limits and logging without retaining unnecessary personal information.
- [ ] Publish privacy and data retention terms.
- [ ] Verify backups and restoration.
- [ ] Confirm applicable business registration, client contract, and payment workflow.
- [ ] Complete a pilot with consent and verify all acceptance criteria.

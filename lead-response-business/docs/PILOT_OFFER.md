## Deliverables
- One branded inquiry form
- One private lead-management dashboard
- Sample draft templates for review (no automatic replies)
- Basic deployment and operational walkthrough
- 30 days of issue triage and minor adjustments, within a mutually agreed limit

## Not included
AI API subscription charges, commercial cloud hosting, SMS/email sending integrations, existing CRM integrations, custom multi-user roles, or 24/7 support unless separately agreed.

## Acceptance criteria
1. A test inquiry saves to the lead dashboard.
2. The authorized operator can view it, draft a sample reply, and update status.
3. Changes persist after a container restart.
4. Client confirms handoff and privacy/security expectations in writing.

## Before using real customer data
Define scope, security responsibilities, legal terms, confidentiality, support hours, service levels, backup/retention rules, and approved data processors. Demo mode should not be advertised as actual generative AI.
